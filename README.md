# MoodMusic

An iOS and watchOS application that helps users discover music based on their mood and energy.

I developed the application using SwiftUI and HealthKit, working with Apple Watch data, Apple Music and Spotify integrations, a structured music research archive and TestFlight distribution.

**Technologies:** SwiftUI, HealthKit, Firebase, Apple Music and Spotify integrations.

**Website:** https://moodmusic.com.tr

This repository introduces the project. Application source code is private.
